Ogun is starting at {{ .Values.publicUrl }} (one replica: ogund and ogun-server in pod {{ include "ogun.fullname" . }}-0).

1. Create the bridge credential once, on a terminal (the daemon only lets an interactive person add credentials):

   kubectl exec -it -n {{ .Release.Namespace }} {{ include "ogun.fullname" . }}-0 -c ogund -- \
     ogun --profile server credentials add server --kind bridge

2. Read the one-time owner enrolment link (written because the store was empty), open it, sign in, then delete it:

   kubectl exec -n {{ .Release.Namespace }} {{ include "ogun.fullname" . }}-0 -c ogun-server -- \
     cat /var/lib/ogun/ogun-server/owner-enrolment.txt
   kubectl exec -n {{ .Release.Namespace }} {{ include "ogun.fullname" . }}-0 -c ogun-server -- \
     rm /var/lib/ogun/ogun-server/owner-enrolment.txt

3. Approver passkeys are confirmed on the host terminal, never in the browser:

   kubectl exec -it -n {{ .Release.Namespace }} {{ include "ogun.fullname" . }}-0 -c ogund -- \
     ogun --profile server approvers confirm <credential_id> <fingerprint>
